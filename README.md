# Grindline

Camo tracker for Modern Warfare 4 on Windows PC. Grindline reads the game picture on your screen and ticks off your camos for you.

**[Download the latest version](https://github.com/Pumkes-Organisation/grindline-releases/releases/latest)**: under *Assets*, pick `Grindline-Setup-<version>.exe`.

This repository only holds the installers and the signed game data that Grindline updates itself from. It contains no source code.

## Install

1. Run `Grindline-Setup-<version>.exe`. It installs for your own Windows account, without admin rights.
2. Windows may say *Windows protected your PC*, because the app is not code-signed yet. Click **More info**, then **Run anyway**.

After that Grindline keeps itself up to date: new versions download in the background and install when you close the app. New game data (weapons, camos) arrives without a restart.

## Privacy

Grindline only looks at the picture on your own screen. It never reads or changes anything inside the game and never presses keys. It goes online only to download updates from this repository.

## Nederlands

Camotracker voor Modern Warfare 4 op pc. Grindline leest het beeld van de game op je scherm en vinkt je camo's zelf af.

**[Download de nieuwste versie](https://github.com/Pumkes-Organisation/grindline-releases/releases/latest)**: kies onder *Assets* het bestand `Grindline-Setup-<versie>.exe`.

1. Start het bestand. Grindline installeert voor je eigen Windows-account, zonder beheerdersrechten.
2. Meldt Windows *Windows heeft uw pc beschermd*? Dat komt doordat de app nog niet ondertekend is. Klik op **Meer informatie** en daarna op **Toch uitvoeren**.

Daarna werkt Grindline zichzelf bij: nieuwe versies worden op de achtergrond gedownload en geïnstalleerd zodra je de app sluit. Nieuwe speldata komt binnen zonder herstart. De app gaat alleen online om updates uit deze repository te downloaden.
