# Live Camo Tracker

Live Camo Tracker was called Grindline up to version 0.1.18. Installed copies update themselves and keep your progress.

Camo tracker for Modern Warfare 4 on Windows PC. Live Camo Tracker reads the game picture on your screen and ticks off your camos for you.

**[Download the latest version](https://github.com/Pumkes-Organisation/grindline-releases/releases/latest)**: under *Assets*, pick `Live-Camo-Tracker-Setup-<version>.exe`.

This repository only holds the installers and the signed game data that Live Camo Tracker updates itself from. It contains no source code.

## Install

1. Run `Live-Camo-Tracker-Setup-<version>.exe`. It installs for your own Windows account, without admin rights.
2. Windows may say *Windows protected your PC*, because the app is not code-signed yet. Click **More info**, then **Run anyway**.

After that Live Camo Tracker keeps itself up to date: new versions download in the background and install when you close the app. New game data (weapons, camos) arrives without a restart.

## Privacy

Live Camo Tracker only looks at the picture on your own screen. It never reads or changes anything inside the game and never presses keys. It goes online to download updates from this repository, and to send your feedback when you click *Send feedback* on the Beta page. With a free beta licence it also checks once a day that the licence still holds.

## Nederlands

Camotracker voor Modern Warfare 4 op pc (tot en met versie 0.1.18 heette de app Grindline). Live Camo Tracker leest het beeld van de game op je scherm en vinkt je camo's zelf af.

**[Download de nieuwste versie](https://github.com/Pumkes-Organisation/grindline-releases/releases/latest)**: kies onder *Assets* het bestand `Live-Camo-Tracker-Setup-<versie>.exe`.

1. Start het bestand. Live Camo Tracker installeert voor je eigen Windows-account, zonder beheerdersrechten.
2. Meldt Windows *Windows heeft uw pc beschermd*? Dat komt doordat de app nog niet ondertekend is. Klik op **Meer informatie** en daarna op **Toch uitvoeren**.

Daarna werkt Live Camo Tracker zichzelf bij: nieuwe versies worden op de achtergrond gedownload en geïnstalleerd zodra je de app sluit. Nieuwe speldata komt binnen zonder herstart. De app gaat online om updates uit deze repository te downloaden en om je feedback te versturen als je op de Beta-pagina op *Feedback sturen* klikt. Met een gratis beta-licentie controleert hij ook eens per dag of die nog geldt.
